# Hardware PCB Portfolio

Some of my hardware design projects. <br />
All the boards are designed by me (schematics + PCB layout) and manually assembled using soldering stations and hot air tools.<br />
I also created firmware (C, C++) for most of these boards, as they contain programmable microcontrollers (MCUs).

**High-Fidelity Audio DAC — ES9038PRO**
A complete 32-bit digital-to-analog converter device with plug-and-play capability.

**Highlights**
- ES9038PRO IC as the processing center with delta-sigma technology.
- Serveral separated super low-noise linear power supplies
- IV converter with 2nd-order low-pass filter
