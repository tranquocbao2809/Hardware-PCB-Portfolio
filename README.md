# Hardware-PCB-Portfolio
Some of my hardware design projects. All the boards are designed by me (schematics + PCB layout) and manually assembled using soldering stations and hot air tools. I also created firmware (C, C++) for most of these boards, as they contain programmable microcontrollers (MCU).
